Part 1

The big idea: grab it, then deal with it

把 originally means “to grasp / to hold.” A 把 sentence literally tells the story in the order it happens: grab the thing → do something to it → end up with a result.

A normal Chinese sentence is Subject–Verb–Object, just like English. 把 picks the object up and moves it in front of the verb, putting a spotlight on what happened to it. Watch:

我喝完茶了 “I finished drinking the tea.” — normal Subject–Verb–Object order

💡 Same facts, new focus. 我喝完茶了 reports what I did. 我把茶喝完了 reports what happened to the tea — it’s gone! That focus on the object’s fate is the whole point of 把.

Why does Chinese even need this?

Because some sentences are impossible without it. In Chinese you can’t say 放书在桌子上 — a verb can’t carry both an object and a place behind it. The object has to move forward, and 把 is what moves it:

请把书放在桌子上。
Qǐng bǎ shū fàng zài zhuōzi shàng.
Please put the book on the table.

🈶 Fun fact: 把 is also the measure word for things you grip — 一把伞 (an umbrella), 一把椅子 (a chair). Same “grab” idea. When you see 把, think of a hand ✋ picking the object up.

Part 3

The four golden rules

Almost every 把 mistake — and every trick question — breaks one of these four. Each rule has a 10-second self-check.

1The object must be specific — something both speakers know

You can only “grab” a thing you can point at: 这本书 (this book), 我的手机 (my phone), 门 (the door we both see). A vague “a/one something” (一个…) can’t go after 把 — for HSK 3, treat 把 + 一个… as always wrong. The object can be a person too: 把他送到医院去 (take him to the hospital), as long as it’s a specific person.

我把那杯牛奶喝了。that glass — specific ✓
我把一杯牛奶喝了。“a glass” — too vague ✗
Self-check: which one is correct?
✓ 这些东西 “these things” is specific; 一些东西 “some things” is not — so it can’t be grabbed by 把.

2The verb can never stand alone — something must follow it

把 promises the listener a result. A bare verb breaks that promise. After the verb you need at least a 了, or better: a result (完 / 好 / 错 / 干净), a direction (到…去 / 过来), a place (在桌子上), a receiver (给我), or a light touch (一下).

我把作业做完了。done — result delivered ✓
我把作业做。did it... and?? ✗
Self-check: which one is correct?
✓ 一下 “a bit” counts as the extra after the verb. A bare 打扫 leaves the sentence hanging.

3Negation & modal verbs go before 把

没 / 别 / 不要 and 想 / 要 / 能 / 会 / 应该 / 可以 all stand in front of 把. Logic: “didn’t grab it” = the grab-and-deal never happened, so the negation applies to the whole 把-package.

我没把作业做完。没 before 把 ✓
我把作业没做完。没 trapped inside ✗
我想把汉语学好。modal before 把 ✓
Self-check: “Don’t put your phone on the bed.”
✓ 别 (don’t) must come before 把, just like 没 and the modals.

4Only “hands-on” action verbs — no feeling, knowing, being

把 needs a verb that physically does something to the object. Verbs of state, feeling or perception change nothing about the object, so they’re banned: 是、有、在、像、喜欢、爱、想(miss)、知道、觉得、希望、认识、看见、听见.

我把那本书看完了。看完 finishes the book ✓
我把那本书喜欢。liking changes nothing ✗ → 我喜欢那本书

Wait — 看见 is on the banned list, so what about 看? Bare 看 (eyes on it) changes nothing, so it can’t take 把 either. But 看完 “finish reading” works through the whole book — verb + result passes. Only the pure-perception results 看见 “catch sight of” and 听见 “hear” can never be rescued this way.

Self-check: which verb can work with 把?
✓ You can open a door — that’s hands-on. Knowing something leaves it untouched, so 知道 can never follow 把.
Part 4

The ending zoo 🦁

Rule 2 says the verb needs “something after it.” These are the six endings you’ll actually meet at HSK 3 — with the classic exam sentence for each.

了 Simple completion

The minimum legal ending: it happened, it’s done. Best with “use-it-up” verbs — 喝了 / 吃了 / 卖了. With 写 or 看, reach for a fuller ending (写完了 / 看完了).

我把咖啡喝了。
Wǒ bǎ kāfēi hē le.
I drank the coffee (it’s gone).

完 / 好 / 错 / 干净 Result

What state did the object end up in? The most common ending in exams.

他把房间打扫干净了。
Tā bǎ fángjiān dǎsǎo gānjìng le.
He cleaned the room (until it was) clean.
老师把我的名字写错了。
Lǎoshī bǎ wǒ de míngzi xiě cuò le.
The teacher wrote my name wrong.

到…去/来 · 过来 · 起来 Direction

Where did the object move? Star of HSK 3 listening dialogues.

他把行李箱搬到楼上去了。
Tā bǎ xínglixiāng bān dào lóushàng qù le.
He carried the suitcase upstairs.
请把菜拿过来。
Qǐng bǎ cài ná guòlai.
Please bring the food over here.

在 + place Placement

Where does the object end up sitting? 把 is mandatory here (see Part 5).

她把手机放在包里了。
Tā bǎ shǒujī fàng zài bāo lǐ le.
She put her phone in the bag.
我把护照忘在家里了。
Wǒ bǎ hùzhào wàng zài jiā lǐ le.
I left (forgot) my passport at home.

给 + person Transfer

Who received the object? Used with 送 give, 借 lend, 还 return, 卖 sell…

我把钱还给他了。
Wǒ bǎ qián huán gěi tā le.
I gave the money back to him.
你能把这本书借给我吗？
Nǐ néng bǎ zhè běn shū jiè gěi wǒ ma?
Can you lend this book to me?

一下 / 一遍 Light touch & repeats

Soften a request or count the action — both count as a legal ending. (遍 “time through” is technically HSK 4, but every teacher uses it — learn it early.)

请把这个句子读一遍。
Qǐng bǎ zhège jùzi dú yí biàn.
Please read this sentence once (aloud).
把空调开一下，好吗？
Bǎ kōngtiáo kāi yíxià, hǎo ma?
Turn on the air conditioning for a bit, OK?
Part 5

When 把 is the only option

Usually 把 is a stylistic choice. But with verb + 在/到 + place the normal order is flat-out ungrammatical, and with verb + 给 + person, 把 is the build the exam expects — HSK loves testing exactly these.

① Moving something to a place: verb + 在/到 + place

放 put, 搬 move, 忘 forget(-leave), 送 deliver… If the place comes right after the verb, the object must move up front with 把.

他放手机在桌子上了。verb can’t carry object + place ✗
他把手机放在桌子上了。object grabbed forward ✓

② Handing a known thing to a person: 送给 / 借给 / 还给 + person

Here 把 isn’t strictly forced — 我送了一个礼物给客人 is fine when the gift is new information. But 给 must be followed immediately by the receiver — the thing can never sit between 送给 and the person. And once the thing is known (那个礼物), natives — and the HSK answer key — grab it with 把.

我送给那个礼物客人了。object stuck inside 送给…person ✗
我把那个礼物送给客人了。把 + object + 送给 + person ✓

🎯 Exam radar: see a verb chunk like 放在 / 搬到 / 忘在 / 借给 / 还给 / 送给 in the word-ordering task? A 把 is almost certainly hiding among the pieces. Build: Subject + 把 + Object + that chunk + place/person.

📋 Pocket cheat sheet — screenshot me

  • Subject + (没/别/想/能/已经) + 把 + Object + Verb + Extra
  • ① Object = specific (这/那/我的…, never 一个…)
  • ② Verb never bare → add 了 / 完 / 好 / 在…/ 到…/ 给…/ 一下
  • ③ 没·别·想·能·应该 always before 把
  • ④ No 是·有·在·像·喜欢·爱·知道·觉得·认识·看见·听见 as the main verb — action verbs only (the 在 inside 放在桌子上 is part of the ending, so it’s fine)
  • ⑤ 放在 / 搬到 / 忘在 + place ⇒ 把 is mandatory · 送给 / 借给 / 还给 + person ⇒ 把 is the expected build in 题 71–75
  • ⑥ Flip side — 被: 我把蛋糕吃了 (spotlight on what I did to it) ↔ 蛋糕被我吃了 (the cake got eaten by me). 把 is followed by the thing affected; 被 by the doer
  • 🎧 Listening tip: requests often start 请把… / 别把… — the thing being discussed is right after 把
