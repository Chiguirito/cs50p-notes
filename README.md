# CS50P — Interactive Lecture Notes

Readable, runnable study notes for Harvard's *Introduction to Programming with Python* (CS50P).
Every code example runs in your browser via [Pyodide](https://pyodide.org) — edit it and press **Run**.

**Live site:** https://chiguirito.github.io/cs50p-notes/

A personal study companion. Lecture *notes* only — no problem-set solutions.
