CS50P — Interactive Lecture Notes

Readable, runnable notes for Harvard's Introduction to Programming with Python. Every example runs in your browser — edit it and press Run.

How to use

Just open a lecture and press ▶ Run on any code box — Python runs right in your browser (it downloads once from the web on first run, ~10 s, then works offline). If Run ever fails to load Python, double-click serve.command instead (or run python3 -m http.server here) and open http://localhost:8000/.
